# suboros — project status

Toy OS for Famicom (NES). Targeting SXROM (MMC1): 128KB PRG ROM, 32KB PRG RAM, 8KB CHR RAM.
Application logic written in C (CC65); interrupt handler and startup in ca65 assembly.

---

## Toolchain

- **cc65** — C compiler (C → 6502 asm). Present at `tools/cc65/bin/cc65.exe`.
- **ca65 / ld65** — assembler and linker from the cc65 suite.
- **Mesen** — emulator at `E:\Portable Software\mesen\`.
- **build.bat** — compiles all C sources, assembles `src/*.asm`, links to `build/suboros.nes`.
- **tools/mkfs.py** — packs files from `in_fs/` into PRG ROM banks 0–6 as SuborFS1 images; generates `build/fs_rom_data.asm`.

## Project files

| File | What it does |
|------|-------------|
| `suboros.cfg` | ld65 linker script. SXROM layout: banks 0–6 as FS data (FILL0–FILL6), bank 7 fixed (PRG_FIXED at $C000). Defines `__STACKSTART__` and CONDES features required by `none.lib`. |
| `src/header.asm` | NES 2.0 header. 8×16KB PRG ROM, 0 CHR ROM (CHR RAM), mapper 1 (MMC1), 32KB battery NVRAM, 8KB CHR RAM. |
| `src/startup.asm` | Reset handler: sei/cld, stack init, 2× vblank wait, zero RAM, init CC65 software stack (`c_sp=$0800`), then `jsr _main`. Holds VECTORS table. |
| `src/nmi.asm` | NMI handler (~60Hz): preserves registers, increments `_frame_count`, sets `_nmi_ready`. IRQ/BRK handler: checks B flag, dispatches syscalls by `sc_num`. |
| `src/zp.asm` | CC65 runtime zero-page slots: `c_sp`, `sreg`, `regsave`, `regbank`, `ptr1–4`, `tmp1–4`. |
| `src/chr_data.asm` | Exports `_ascii_chr_data` via `.incbin "../chr/ascii.chr"`. |
| `src/nes.h` | Hardware register macros: `PPU_*`, `APU_*`, `JOYPAD1`, `PPU_SCROLL`, `CTRL_*` / `MASK_*` flags. `mmc1_write_reg` declaration. |
| `src/syscall.h` | Syscall numbers, ZP register declarations (`sc_num`, `sc_p0–5`, `sc_rv0–3`), and caller macros (`SC_PRINT`, `SC_BEEP`, `SC_SET_PRG_BANK`, `SC_FS_*`). |
| `src/syscalls.c` | Syscall implementations: `put_string` (PPU nametable write), `beep` (APU pulse 1), `set_prg_bank` (MMC1 PRG RAM bank via CHR0 register). |
| `src/fs.c` | SuborFS1 filesystem: mount/open/close/seek/read/getbyte. Banked copy saves/restores `prg_bank_cur` around MMC1 switch. |
| `src/fs.h` | SuborFS1 structs, constants, extern declarations, and `SC_FS_*` caller macros. |
| `src/main.c` | All application logic. See boot sequence below. |
| `chr/ascii.chr` | 8KB CHR binary. ASCII-mapped font; printable ASCII ($20–$7F) is usable. |
| `tools/mkfs.py` | Builds SuborFS1 ROM images. Packs files from `in_fs/<slot>/` into BANK0–BANK6 segments; emits TOC and mount table into RODATA. Filename shortening: first 4 + `~` + last 3 chars of the dot-stripped name. |

## Memory map (runtime)

```
$0000-$00FF   Zero page      — CC65 runtime slots + syscall registers (sc_num, sc_p0-5, sc_rv0-3)
$0100-$01FF   Stack          — hardware-fixed, 256 bytes
$0200-$07FF   RAM            — CC65 BSS (globals, FS mount/handle tables at $0200/$020C)
$6000-$7FFF   WRAM (PRG RAM) — 8KB window into 32KB physical PRG RAM (banked via MMC1 CHR0 reg)
$8000-$BFFF   PRG ROM banks 0-6 — switchable via MMC1; used for SuborFS1 file data
$C000-$FFFF   PRG ROM bank 7  — fixed. All code/data/TOC here. Vectors at $FFFA.
```

PPU / VRAM:
```
$0000-$0FFF   Pattern table 0 — CHR RAM, loaded with ascii.chr at boot
$1000-$1FFF   Pattern table 1 — CHR RAM, unused
$2000-$23FF   Nametable 0     — 32x30 tile indices (visible screen)
$23C0-$23FF   Attribute table — palette select per 2x2 tile block
$3F00-$3F1F   Palettes        — 4 BG + 4 sprite palettes, 4 colours each
```

## Syscall interface

Caller fills ZP registers and executes `BRK #0`. IRQ handler checks the B flag to distinguish BRK from hardware IRQ, then dispatches on `sc_num`:

| `sc_num` | Name | Inputs | Outputs |
|----------|------|--------|---------|
| 0 | `SYS_PUT_STRING` | p0=x, p1=y, p2/p3=str ptr | — |
| 1 | `SYS_BEEP` | p0=freq, p1=dur | — |
| 2 | `SYS_SET_PRG_BANK` | p0=bank (0–3) | — |
| 3 | `SYS_FS_MOUNT` | p0/p1=toc ptr, p2=device | rv0=slot |
| 4 | `SYS_FS_OPEN` | p0=slot, p1/p2=name, p3/p4=va | rv0=handle |
| 5 | `SYS_FS_UNMOUNT` | p0=slot | rv0=ok |
| 6 | `SYS_FS_STAT` | p0=slot, p1/p2=name | rv0/rv1=size |
| 7 | `SYS_FS_CLOSE` | p0/p1=va | rv0=ok |
| 8 | `SYS_FS_SEEK` | p0/p1=va, p2-p4=offset24 | — |
| 9 | `SYS_FS_READ` | p0/p1=va, p2/p3=dest, p4/p5=n | rv0/rv1=n_read |
| 10 | `SYS_FS_GETBYTE` | p0/p1=va | rv0=byte, rv1=err |

## Boot sequence

1. Reset: sei/cld, stack, 2× vblank, zero RAM, CC65 stack init
2. `main()`:
   a. `fs_init()` — zero mount/handle tables
   b. Mount any ROM filesystems from `fs_rom_mount_table` (generated by mkfs.py)
   c. Init APU, disable PPU
   d. Load CHR font, palette, clear nametable
   e. Enable BG; optional PRG RAM POST (only if a button is held at boot)
   f. `browser_enumerate()` — scan all mount table slots, collect file names
   g. Clear screen; enable NMI + full rendering
   h. File browser loop: D-pad scrolls, A opens and streams file to screen
